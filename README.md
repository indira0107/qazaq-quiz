# QAZAQ Quiz — Netlify нұсқасы

## Орнату

1. Осы жобаны GitHub репозиторийіне жүктеңіз.
2. Netlify → **Add new site → Import an existing project** арқылы репозиторийді таңдаңыз.
3. Netlify → **Site configuration → Environment variables** бөлімінде `TEACHER_PASSWORD` айнымалысын қосып, оқытушыға арналған құпиясөзді жазыңыз.
4. Deploy аяқталған соң негізгі сайт сілтемесін ашыңыз. QR-код сол сілтемеден автоматты түрде жасалады.
5. Оқытушы нәтижелерді `https://СІЗДІҢ-САЙТЫҢЫЗ.netlify.app/teacher.html` бетінен көреді.

## Маңызды

- Студенттер негізгі сайтты QR арқылы ашады.
- Әр студенттің аты, ұпайы, әр сұраққа берген жауабы және уақыты Netlify Blobs ішінде сақталады.
- Оқытушы бетінде ТОП-3 және CSV жүктеу бар.
- ZIP-ті жай ғана Drag & Drop арқылы салу build пен Functions-ті қоспайды. Git арқылы импорттаңыз немесе Netlify CLI қолданыңыз.
